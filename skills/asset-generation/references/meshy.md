# Meshy API decisions

Verified against official documentation on 2026-09-28. Recheck when starting a batch; these are a snapshot, not permanent guarantees.

- [Text to Image](https://docs.meshy.ai/en/api/text-to-image): `/openapi/v1/text-to-image`, with `gpt-image-2`, Nano Banana variants including `nano-banana-pro`, and newer GPT variants documented. Respect the user's stated model preference; use a successor only if accepted. Image to Image is the companion endpoint for reference-guided variants.
- [Image to 3D](https://docs.meshy.ai/en/api/image-to-3d): `/openapi/v1/image-to-3d`; `meshy-7.1` is the documented `latest` standard model. Optional 2k/4k geometry resolution and 2k/4k/8k texture resolutions have different costs and compatibility. Standard masters and smart-topology game meshes serve different purposes. Use exact supported parameters, not labels guessed from the website. Input may reference a completed API image task or an uploaded image. Preserve the model version, not just the moving alias.
- [Rigging](https://docs.meshy.ai/en/api/rigging) and [Animation](https://docs.meshy.ai/en/api/animation): check API-supported body types and face limits. The current rigging API documents standard textured humanoids and a 300,000-face limit for task inputs. Web-app capabilities can differ. Inspect returned skeletons instead of assuming finger articulation.
- [UV Unwrap](https://docs.meshy.ai/en/api/uv-unwrap), [Retexture](https://docs.meshy.ai/en/api/retexture), and remeshing are conditional postprocessing, not mandatory credit-spending stages.
- [API pricing](https://docs.meshy.ai/en/api/pricing): at this snapshot, a standard Meshy 7.1 image-to-3D request with 4K textures is 30 credits, optional Ultra geometry adds 5; auto-rig is 5, animations are 3/action, UV unwrap is 5. GPT Image and Nano Banana Pro text-to-image are 9/image. Recalculate from current documentation, account balance and actual task usage; do not use web-app prices as API prices.

No general free-regeneration API parameter/endpoint was verified in the Image to 3D reference at this date. Web-app Free Retry is not proof of API eligibility. Check current official support and the account's entitlement before describing a retry as free. A new normal generation request is budgeted as paid unless proven otherwise.

Discover existing project clients before writing a replacement. The Amber Road workspace has `tools/meshy_assets.py`, `tools/motion_pipeline.py`, `tools/export_vault_library.py` and `tools/package_complete_library.py`; these are useful implementations to inspect if present, not dependencies of this skill. Reuse their ledger/resume behavior, but verify their hard-coded prices, models, paths and budget against the new task. Keep credentials in local ignored storage or environment variables. Do not copy them into portable skills or packages.

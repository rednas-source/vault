# Economy surface

Mode: Operate. Extend the existing Vault workspace and its dark/light appearance. The user requested the previously discussed Nordnet-like market overview and four cooperating paper-trading roles. This is an implementation of that pinned working pattern, not a new visual identity or an open concept competition.

THESIS: Follow market evidence, test a decision with simulated cash, and inspect how it was reached.

OWN-WORLD: Vault's compact sans typography, neutral theme surfaces, accent selection, Phosphor icons, line-divided data tables, standard inputs and restrained buttons. Positive and negative financial amounts add scoped green/red text, accompanied by explicit numeric signs.

STORY: Markets search/watchlist → instrument quote/history → Sandbox experiment → four-agent discussion → journal and paper fill → export/comparison. Setup is a peer view and remains visible without provider keys. A synthetic demo is isolated from real-market experiments.

FIRST VIEWPORT: Economy heading, paper-only status and Markets/Sandbox/Decision journal/Setup navigation. Markets pairs an instrument table with quote detail. Sandbox identifies the experiment and currency before portfolio/cash/return/benchmark values. Missing keys and missing prices are explicit.

FORM: Preserve the existing shell; six top navigation sections remain usable on a 390px phone. Desktop uses table/detail and portfolio/decision columns; phones stack them with contained table scrolling. No new image assets, gradients, decorative cards or motion are required. Standard task interaction is the signature: each reviewed role contributes to one inspectable decision rather than a decorative chatbot.

Quality bar: no made-up market data or agent opinions; reliable numeric formatting (including USDT), explicit data timestamps, stable provider setup, private account boundaries, readable tables and form recovery, all controls reachable on phones. Exact trade arithmetic and risk limits are server-owned. Capture evidence in `.impeccable/review/economy-desktop.png`, `economy-markets-desktop.png`, and `economy-mobile.png`.

Extension 2026-10-15: preserve the same Operate world. Add catalogue filters/pagination, time-range history, timed experiment controls with model/cost snapshots, four parallel viewpoints plus debate, Analytics and a public Games directory in the incumbent typography. Apps stays last; phone navigation always uses accessible labelled icons. Games is a flat, two-column link directory that stacks on phones, with no installed-game claims. Quality bar adds truthful catalogue-versus-quote coverage, recorded versus illustrative costs, explicit scan scope/progress, no API spend without configured rates/budget, and private API authentication unaffected by public /games.
